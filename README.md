# Penelopa.ai

**Continuous improvement for AI coding agents.**

Penelopa.ai turns your Codex and Claude Code sessions into practical, reusable improvements. Install the hook once, keep working as usual, and review recommendations based on recurring patterns across your projects.

[Open your dashboard](https://penelopa.ai/dashboard)

## What you get

- **Automatic session capture** — connect Codex, Claude Code, or both with one installer.
- **Actionable recommendations** — surface repeated issues, missing checks, and workflow improvements from your agent sessions.
- **A personal dashboard** — see activity, saved sessions, and recommendations in one place.
- **Telegram notifications** — get notified when new recommendations are ready.
- **Reliable delivery** — transcript data is queued locally and retried when a connection is unavailable.

## Get started

Run the installer from the terminal in which you use your coding agent. It creates a personal access token, configures the relevant hooks, and prints a private dashboard link when it finishes.

### macOS and Linux

```sh
curl -fsSL https://penelopa.ai/script | sh
```

### Windows PowerShell

```powershell
$installer = Join-Path $env:TEMP "penelopa-auto-improve.ps1"
Invoke-WebRequest -Uri "https://penelopa.ai/script.ps1" -OutFile $installer
& $installer
```

By default, the installer configures both Codex and Claude Code. To configure only one agent, pass `--agent codex` or `--agent claude` on macOS/Linux; on Windows, use `-Agent codex` or `-Agent claude`.

## After installation

1. If Codex asks you to review new hooks, approve the `Stop` and `SessionEnd` hooks.
2. Work normally in Codex or Claude Code.
3. Open the [dashboard](https://penelopa.ai/dashboard) to view your sessions and recommendations. Use the private link printed by the installer to access your personal data.
4. Optionally connect Telegram from the dashboard to receive recommendation alerts.

## How it works

Penelopa.ai reads the transcript generated by your coding agent after a stop or at the end of a session. It uploads new transcript segments in the background, looks for patterns across your work, and turns those patterns into recommendations you can apply to future tasks.

## Useful commands

```sh
# Show installer options
curl -fsSL https://penelopa.ai/script | sh -s -- --help

# Configure only Codex
curl -fsSL https://penelopa.ai/script | sh -s -- --agent codex

# Request a fresh personal token
curl -fsSL https://penelopa.ai/script | sh -s -- --force-new-token
```
